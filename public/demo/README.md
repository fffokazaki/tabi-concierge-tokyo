## 構成

1. タイトル: 東京都の約9,600のオープンデータを、旅の相棒に。
2. `PLAN`: プロフィール入力から、出典付きプランの表示まで
3. `DECLINE`: ラーメンの粒度不足を理由付きで回答しない画面
4. クロージング: 答えられないときは、答えません。

First Stage資料の #3・#4 では、この1本に含まれる `PLAN` と `DECLINE` の2シーンを使います。
