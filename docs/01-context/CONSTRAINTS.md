# CONSTRAINTS.md - プロジェクト制約事項

> 本書はハッカソン主催者（東京都 / GovTech東京）の規定と、2026-08-15 チーム合意で確定した制約を記録する。数値・期限は Notion の一次情報（[PROJECT.md](./PROJECT.md) §1 参照）に従う。

## 1. 技術的制約

### プラットフォーム制約

- **対応OS**: 未定（POC はブラウザ動作のため OS 依存を持たない想定）
- **対応ブラウザ**: モダンブラウザ（収録・提出は開発者環境のブラウザで実施）
- **モバイル対応**: スマートフォン想定の画面設計（実機検証は未実施）

### 開発環境制約

- **プログラミング言語**: TypeScript。フロントエンドは React 19、Worker は workerd 上で動く（Node ではない）
- **フレームワーク**: React 19 ＋ Vite 8。Worker 側は Hono
- **注意**: デザインプロトタイプ（`public/showcase/`）は `fonts.googleapis.com` に依存するため**オフラインでは表示が崩れる**。収録前にネットワーク接続を確認すること
- **データベース**: Cloudflare D1（ADR-007）。オープンデータの格納と未回答ログに用途を限定する（[DATABASE.md](../02-design/DATABASE.md) 参照）

### インフラ制約

- **ホスティング環境**: Cloudflare Workers（アカウント `tokyo_odh_091`・ハッカソン事務局発行）。<https://tabi-concierge-tokyo.tokyo-odh-091.workers.dev>
- **最大同時接続数**: 未定（First Stage はライブデモ不可のため、収録時点で負荷要件なし）
- **ストレージ容量**: 利用オープンデータは提出登録の上限に合わせ最大10件に限定

## 3. 法的・規制制約

### コンプライアンス要件

- **適用法規**: 著作権法（引用・出典表示）。個人情報は取り扱わない方針のため個人情報保護法上の要配慮事項は現時点で該当なし
- **業界標準**: 自治体標準オープンデータセット（千代田区 公共施設一覧などが準拠）
- **監査要件**: 該当なし（ハッカソン提出物のため）

### ライセンス制約

- **使用可能ライセンス**: 東京都オープンデータカタログ掲載データは **CC BY 4.0**。出典表示のみで、加工・組込・商用を含む二次利用が可能
- **禁止（二次利用不可）**: カタログに掲載されていない「公表されただけのデータ」（都HPの資料等）。著作権は都が保有し、原則として二次利用できない。事務局の「公表であって公開ではない」はこの区別への注意喚起
- **商用利用制限**: カタログ掲載データについては、出典（東京都）を表示すれば商用化まで含めて制限なし
- **設計上の帰結**: 本サービスは全回答に出典を強制付与するため、CC BY の表示義務を**アーキテクチャレベルで自動的に満たす**（コンプライアンスが機能になる）

### 提出物の著作権ルール（主催者規定）

- BGM は使用しない
- 音声合成は合理的理由がある場合のみ使用可
- 『いらすとや』の素材は1資料あたり最大20個まで
- Google Map を使用する場合はロゴ・帰属表示を隠さない（地図は OpenStreetMap 系を推奨）
- 引用は出典を明記する

### データ保護要件

- **個人情報保護**: 旅行者のプロフィール入力（同行者・興味・ペース）は個人を特定しない粒度に留める
- **データ保存期間**: 未定（利用ログの保持方針は Final Stage で決定）
- **データ削除要件**: 未定

## 7. 制約の優先順位

### クリティカル（変更不可）

1. 2026-08-23（日）17:00 の提出締切と提出形式（PowerPoint または PDF・16:9 横・画面キャプチャ 1600×900px を1〜3点・利用オープンデータは最低1件〜最大10件を「データURL＋タイトル」で登録）
2. First Stage は **2分厳守**（超過は強制終了）・**ライブデモ一切不可**（動くデモは資料内に動画として埋め込む）
3. 出典表示（CC BY 4.0）とカタログ外データの二次利用禁止

### 重要（変更には承認必要）

1. POC スコープ（全件動的取り込みをしない／代表エリアに絞る）
2. バックエンドを主催者提供スタック（OpenCode ＋ Cloudflare）で完結させる方針

### 推奨（ガイドライン）

1. プレゼンで使う数字は「9,600 ／ 1日200PV ／ 30分→3分」の3つに絞る
2. 提出後ただちに収録枠を予約する（30分単位・早い者順）
3. 地図は OpenStreetMap 系を優先する
