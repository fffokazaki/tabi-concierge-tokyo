### ACE-9-2: ランタイムの同一性は、実行中のランタイム自身に答えさせて確認する

| Category | testing | Origin | PR #9 |
| Date | 2026-08-15 |
| Helpful | 0 | Harmful | 0 |
| Status | active |

「ローカルも本番と同じランタイムで動いているか」は設定ファイルの読み合わせでは確認できない。ツールが黙って別ランタイムへフォールバックしても設定は正しいままだからである。ヘルスチェックに `navigator.userAgent` のようなランタイム自己申告値を含めておくと、ローカルと本番の両方で1回 curl するだけで実測できる。環境差が疑われる問題（本番だけ壊れる系）の切り分け時間も短縮される。
