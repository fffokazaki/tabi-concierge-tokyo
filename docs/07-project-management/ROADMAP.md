# ROADMAP.md - プロジェクトロードマップ

## 1. プロジェクト概要

### ビジョン

9,600のオープンデータを、旅の相棒に。「1データ＝1アプリ」の時代を、旅から終わらせる。

### ミッション

訪日観光客向けの AI 旅行ガイドを入口として、東京都オープンデータカタログの約9,600データセットに会話から到達できるようにし、答えられなかった質問を都へ還元してデータそのものを育てる。

## 4. リソース計画

### チーム構成

チームshiwata。役割は**提出資料（16:9）のチーム紹介パート**で提示する（必須4項目の④）。

> 提出資料（16:9・14枚・8/23 締切・[submission-deck.md](../submission-deck.md)）と First Stage スライド（8枚・[first-stage-presentation.md](../first-stage-presentation.md)）は**別のデッキ**。後者はチーム紹介スライドを含まない（2分に収めるため）。スライド番号を書くときはどちらのデッキか明示すること。

### 予算配分

専用予算なし。主催者提供スタック（OpenCode ＋ Cloudflare）の利用枠内で完結させる。

## 5. 依存関係とクリティカルパス

### 主要な依存関係

| 依存元 | 依存先 | 内容 |
| ------ | ------ | ---- |
| 画面キャプチャ | 本番アプリの実画面 | **2026-08-21 に一本化**: 提出資料 [submission-deck.md](../submission-deck.md) のスライド6（プラン生成）・7（あなたへ）・8（ラーメンに答えない）を、本番URLから 1600×900px で切り出す |
| デモ動画 | 画面イメージ | 画面が固まらないと録画できない |
| 収録枠予約 | 提出フォーム送信 | 提出しないと予約できず、枠は早い者順 |
| MCP 接続 POC | オープンデータの同梱 | データがないとツール呼び出しの意味が示せない |

### クリティカルパス

```
オープンデータ同梱 → 代表エリア画面イメージ → デモ動画録画 → 提出資料完成
                                                            → 提出（8/23 17:00）→ 収録枠予約 → 収録
```

最短経路上のどこが遅れても提出日に直撃する。特に「提出 → 収録枠予約」は早い者順のため、締切ぎりぎりの提出は収録枠の選択肢を失う。

## 6. リスクと対策

詳細は [RISKS.md](./RISKS.md) を参照。ロードマップ上の主要リスクのみ再掲する。

| リスク | 対策 |
| ------ | ---- |
| 提出締切に画面・動画が間に合わない | モック（静止画＋カーソル操作）でも成立する構成にしてある |
| 収録枠が埋まる | 提出直後に予約する |
| 2分超過による強制終了 | 1分55秒着地で設計し、事前計測する |
